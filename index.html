1Context

Why Python visualization? (Tableau users' perspective)

This is something interviewers actually ask: "Why would you use Python for visualization instead of Tableau or Power BI?" The answer isn't that one is better — they serve different purposes.

📊 Tableau — communicate & dashboard
  • Interactive dashboards for non-technical stakeholders
  • Rapid drag-and-drop visual exploration
  • Polished presentation-ready visuals with minimal effort
  • VP-level reporting that non-technical users can self-serve
🐍 Python — analyse & automate
  • EDA inside a pipeline — no one there to drag and drop
  • Reproducible: notebook is both analysis and documentation
  • Correlation heatmaps, pairplots, multi-panel grids — impossible or clunky in Tableau
  • Charts sit right next to data-cleaning and modelling code
🌉 Tableau bridge
In Tableau, you explore data by pointing and clicking. In Python, you explore data by writing code. The analytical thinking is identical. The interface is different. By the end of this lecture, you'll be able to do everything Tableau's chart builder does — plus some things Tableau simply cannot do easily.
🌉 SQL bridge
You write a GROUP BY query → get numbers in a table → Tableau visualizes it as a chart. Python does both: Pandas processes data (like SQL) and Seaborn visualizes it (like Tableau), all in one notebook.
2Foundations

Matplotlib: exactly four things you need

Matplotlib is a massive library. We are learning exactly four things from it — enough to produce professional-looking charts for every EDA notebook or interview submission.

python — environment setup
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

vg = pd.read_csv('vgsales.csv')
vg.head()
1. Figure Sizing
plt.figure(figsize=(10, 5))
Width × height in inches. Without this, charts can be too small or too large. Like resizing a chart element in Tableau's dashboard view.
2. Titles & Axis Labels
plt.title('...')
plt.xlabel('...')
plt.ylabel('...')
A chart without labels is like a table without column headers.
3. plt.show()
Renders the chart cleanly and clears figure state for the next chart. Always call it explicitly — good practice even in Colab where plots auto-render.
4. Figure vs Axes
Figure = the entire canvas.
Axes = individual chart area within it. For now: one chart per figure. In styling we'll put two side by side.
python — all four together
plt.figure(figsize=(10, 5))
plt.title('Placeholder Chart')
plt.xlabel('X Axis Label')
plt.ylabel('Y Axis Label')
plt.show()

4Univariate analysis

Categorical data: countplot and barplot

Univariate analysis looks at one variable at a time. We always start with categorical variables — they're the simplest to visualize. Question: "Which genre has the most games in our catalog?"

sns.countplot() — frequency of each category

python
plt.figure(figsize=(12, 5))
sns.countplot(data=vg, x='Genre')
plt.title('Number of Games by Genre')
plt.xlabel('Genre')
plt.ylabel('Count')
plt.show()
python — sorted horizontal (cleaner for long labels)
plt.figure(figsize=(10, 6))
sns.countplot(data=vg, y='Genre',
              order=vg['Genre'].value_counts().index)
plt.title('Number of Games by Genre (Sorted)')
plt.xlabel('Count')
plt.ylabel('Genre')
plt.show()
✓ Pro tip — always sort categorical bar charts
Sort by frequency unless there's a natural order (months, ratings). It makes the chart immediately readable and signals analytical attention to interviewers.
🌉 Tableau + SQL bridge
Tableau: drag Genre to Columns → system auto-adds count to Rows. sns.countplot() does the count automatically.
SQL equivalent: SELECT Genre, COUNT(*) AS game_count FROM vgsales GROUP BY Genre ORDER BY game_count DESC;

sns.barplot() — aggregated metric per category

Question: "Which genre generates the highest average global sales?" Now we're comparing an aggregate (mean), not a count.

python
plt.figure(figsize=(12, 5))
sns.barplot(data=vg, x='Genre', y='Global_Sales')
plt.title('Average Global Sales by Genre')
plt.xlabel('Genre')
plt.ylabel('Average Global Sales (millions)')
plt.show()
💡 countplot vs barplot
countplot: How many items in each category? (frequency — no y variable needed)
barplot: What is the average of a value across categories? (aggregated metric — requires both x and y)

The black lines on barplot bars are confidence intervals — a long line means the data within that category is spread out.

Pie chart (brief mention)

⚠️ Avoid pie charts in professional EDA
Pie charts show proportions but human eyes compare lengths (bars) far better than angles (slices). In interviews and professional notebooks, sorted bar charts with percentage labels are almost always preferred. Use pie charts only when explicitly requested.

5Univariate analysis

      
Continuous data: histogram and KDE

      
For continuous variables you're analyzing a distribution: What's the shape? Where's the center? How spread out is the data? Are there outliers? These questions appear in virtually every Data Analyst interview.


      
sns.histplot() — frequency bins

      
python
plt.figure(figsize=(10, 5))
sns.histplot(data=vg, x='Global_Sales', bins=30)
plt.title('Distribution of Global Sales')
plt.xlabel('Global Sales (millions)')
plt.ylabel('Frequency')
plt.show()

      
The distribution will be heavily right-skewed: most games have low sales, and a small number have extremely high sales. This is a very common real-world pattern — income, website traffic, app downloads, sales figures.


      

        Income analogy: Most people earn a moderate amount, a smaller number earn a lot, and a tiny number earn an enormous amount. The histogram has a tall cluster on the left and a long tail stretching right.
      


      

        
💡 Choosing bins

        More bins = finer detail, potentially noisy. Fewer bins = smoother, may hide patterns. Start with the default, then adjust. 20–50 bins is usually a good range. If the shape looks blocky, add bins; if it looks jagged, remove some.
      


      
sns.kdeplot() — smoothed density curve

      
python
plt.figure(figsize=(10, 5))
sns.kdeplot(data=vg, x='Global_Sales')
plt.title('KDE Plot of Global Sales')
plt.xlabel('Global Sales (millions)')
plt.ylabel('Density')
plt.show()

# Overlay KDE on histogram (professional standard)
plt.figure(figsize=(10, 5))
sns.histplot(data=vg, x='Global_Sales', bins=30, kde=True)
plt.title('Histogram with KDE Overlay')
plt.show()

      

        
✓ Interview pro tip — histogram + KDE overlay

        Showing a histogram with kde=True signals you understand distribution analysis at a professional level. The y-axis of a KDE plot is density (not count) — the area under the curve sums to 1.

6Univariate analysis

      
Box plot and the IQR rule

      
The box plot is your outlier detection tool. It compresses the entire distribution into five numbers and makes outliers immediately visible.


      

        
      


      
python
plt.figure(figsize=(10, 5))
sns.boxplot(data=vg, x='Global_Sales')
plt.title('Box Plot of Global Sales')
plt.xlabel('Global Sales (millions)')
plt.show()


      
The IQR outlier rule is something interviewers ask you to explain:

      

        
FormulaMeaning

        
IQR = Q3 − Q1Width of the middle 50% of the data

        
Lower Bound = Q1 − (1.5 × IQR)Points below this are potential outliers

        
Upper Bound = Q3 + (1.5 × IQR)Points above this are potential outliers

      


      

        
Quiz 1

        
You create a histogram of customer purchase amounts and see a tall peak on the left with a long tail extending to the right. What does this tell you?

        

          
A) The distribution is normally distributed

          
B) The distribution is left-skewed

          
C) The distribution is right-skewed (positively skewed)

          
D) The distribution is uniform

        

        
A tall peak on the left with a long tail to the right is the definition of right-skewed (positively skewed) data. Most values are low, with a few extreme high values pulling the tail rightward. Common real-world examples: income, sales, website traffic.

7Bivariate analysis

      
Continuous vs Continuous: scatter plot and line plot

      
Bivariate analysis looks at two variables together. Question: "Do games that sell well in North America also sell well in Europe?"


      
sns.scatterplot() — relationship between two continuous variables

      
python
plt.figure(figsize=(8, 6))
sns.scatterplot(data=vg, x='NA_Sales', y='EU_Sales')
plt.title('NA Sales vs EU Sales')
plt.xlabel('North America Sales (millions)')
plt.ylabel('Europe Sales (millions)')
plt.show()

# Add genre dimension with hue
plt.figure(figsize=(10, 6))
sns.scatterplot(data=vg, x='NA_Sales', y='EU_Sales', hue='Genre')
plt.title('NA Sales vs EU Sales by Genre')
plt.show()


      

        
Pattern in scatter plotMeaning

        
Dots from bottom-left → top-rightPositive correlation: as one increases, the other tends to increase

        
Dots from top-left → bottom-rightNegative correlation: as one increases, the other tends to decrease

        
Random cloud, no patternNo correlation: the variables move independently

      


      
sns.lineplot() — trends over time or ordered sequences

      
python
year_counts = vg.groupby('Year')['Name'].count().reset_index()
year_counts.columns = ['Year', 'Game_Count']
year_counts = year_counts.dropna()

plt.figure(figsize=(12, 5))
sns.lineplot(data=year_counts, x='Year', y='Game_Count')
plt.title('Number of Game Releases Over Time')
plt.xlabel('Year')
plt.ylabel('Number of Games Released')
plt.show()

      

        
💡 Scatter vs Line

        Use scatter plots when you want to see the relationship between two variables at a point in time. Use line plots when one of your variables represents time or a natural sequence.
      


      

        
Quiz 2

        
A scatter plot of "Hours Studied" (x) vs "Exam Score" (y) shows dots forming a pattern from bottom-left to top-right. What does this indicate?

        

          
A) Negative correlation

          
B) No correlation

          
C) Positive correlation

          
D) The variables are categorical

        

        
Bottom-left to top-right is the visual signature of positive correlation: as one variable increases, the other tends to increase too. This is the most common pattern interviewers ask you to identify in a scatter plot.

8Bivariate analysis

      
Categorical vs Continuous: box plot and bar plot

      
The most common pattern in real-world analysis: "Compare revenue across regions." "Compare salaries across departments." One categorical variable defines groups; one continuous variable is compared. This is also Tableau's most natural use case.


      
Grouped box plot — full distribution per category

      
python
top_platforms = vg['Platform'].value_counts().head(8).index
vg_top = vg[vg['Platform'].isin(top_platforms)]

plt.figure(figsize=(12, 6))
sns.boxplot(data=vg_top, x='Platform', y='Global_Sales')
plt.title('Global Sales Distribution by Top 8 Platforms')
plt.xlabel('Platform')
plt.ylabel('Global Sales (millions)')
plt.show()


      
Grouped bar plot — mean per category

      
python
plt.figure(figsize=(12, 6))
sns.barplot(data=vg_top, x='Platform', y='Global_Sales')
plt.title('Average Global Sales by Platform')
plt.xlabel('Platform')
plt.ylabel('Average Global Sales (millions)')
plt.show()

# Add a second categorical dimension with hue
plt.figure(figsize=(14, 6))
sns.barplot(data=vg_top, x='Platform', y='Global_Sales', hue='Genre')
plt.title('Average Global Sales by Platform and Genre')
plt.legend(bbox_to_anchor=(1.05, 1), loc='upper left')
plt.tight_layout()
plt.show()

      

        
💡 Box plot vs bar plot for categorical vs continuous

        Box plot: shows full distribution — median, spread, outliers per group. Use when you want to compare variability, not just averages.

        Bar plot: shows mean (or other aggregate). Use when the summary number is what matters.


        In interviews: showing both and explaining why demonstrates thorough analysis.
      

    


    
    

      
9Multivariate

      
Correlation heatmap

      
The single most commonly referenced visualization in Data Analyst interviews. Instead of making scatter plots one pair at a time, a heatmap shows relationships between all numerical variables at once.


      
python — compute then visualize
vg.corr(numeric_only=True)  # compute correlation matrix

plt.figure(figsize=(10, 8))
sns.heatmap(vg.corr(numeric_only=True), annot=True, cmap='coolwarm')
plt.title('Correlation Heatmap of Video Game Sales')
plt.show()


      
Correlation values (from real data)
              NA_Sales  EU_Sales  JP_Sales  Other_Sales  Global_Sales
NA_Sales          1.00      0.77      0.45         0.63          0.94
EU_Sales          0.77      1.00      0.44         0.65          0.90
JP_Sales          0.45      0.44      1.00         0.29          0.61
Other_Sales       0.63      0.65      0.29         1.00          0.75
Global_Sales      0.94      0.90      0.61         0.75          1.00


      
How to read the color scale:

      

      

        −1 (perfect negative)0 (no correlation)+1 (perfect positive)
      


      
Key observations from this heatmap:

      
    
        
  • NA_Sales and Global_Sales: 0.94 — North American sales are the strongest predictor of global sales.
    • 
        
  • JP_Sales has the weakest correlations — the Japanese market behaves somewhat independently of other regions.
    • 
        
  • Diagonal is always 1.0 — every variable is perfectly correlated with itself.
    • 
      


      

        
ParameterEffectWhen to use

        
annot=TruePrints correlation values inside cellsAlways — colors alone make precise interpretation difficult

        
cmap='coolwarm'Red=positive, Blue=negative, White=near-zeroStandard for correlation heatmaps

        
fmt='.2f'Format annotation to 2 decimal placesWhen default format is too long

      


      

        
🌉 Tableau bridge — Python's clear advantage

        Tableau does not natively produce correlation heatmaps. You'd need to compute correlations externally and then build a custom chart. This is one of the clearest examples of Python's advantage for analytical visualization — exactly the framing interviewers are looking for.
      


      

        
Quiz 3

        
In a correlation heatmap, a cell shows the value 0.05 between two variables. What does this indicate?

        

          
A) Strong positive correlation

          
B) Strong negative correlation

          
C) Weak or no linear correlation

          
D) The variables are identical

        

        
A correlation coefficient close to 0 indicates little to no linear relationship — the two variables move independently. A value of 0.05 is near-zero. Important: correlation only measures linear relationships; two variables can have a strong non-linear relationship and still show a near-zero correlation.

10Multivariate

      
Pairplot — scatter plots behind the numbers

      
The heatmap gives you correlation numbers. Pairplot gives you the scatter plots behind those numbers — so you can visually inspect the shape of each relationship, not just its coefficient.


      
python — one line, full grid
sns.pairplot(vg[['NA_Sales', 'EU_Sales', 'JP_Sales', 'Global_Sales']])
plt.show()

# With hue — color by category
top_genres = vg['Genre'].value_counts().head(4).index
vg_subset = vg[vg['Genre'].isin(top_genres)]
sns.pairplot(vg_subset[['NA_Sales','EU_Sales','JP_Sales','Global_Sales','Genre']],
             hue='Genre')
plt.show()


      
What one line gives you:

      
    
        
  • Scatter plots for every variable pair (off-diagonal cells)
    • 
        
  • Distribution plots for each variable (diagonal cells)
    • 
        
  • An instant visual overview of all relationships in your data
    • 
      


      

        
Cell typeWhat it shows

        
Off-diagonalScatter plot of row variable (y) against column variable (x). Look for linear trends, clusters, outliers.

        
DiagonalDistribution of each variable (histogram or KDE). With hue: overlapping curves per category.

        
SymmetryGrid is symmetric across the diagonal — row 2 col 3 shows same relationship as row 3 col 2, with axes flipped.

      


      

        
🌉 Tableau bridge — Python's efficiency advantage

        To reproduce a pairplot in Tableau: create a separate scatter plot sheet for every variable pair, a histogram sheet for each variable, and arrange them all in a dashboard. What Seaborn does in one line would take 10–15 minutes of manual work in Tableau.

        Clean, readable, works well in both light and dark presentation settings. Set it once at the top of your notebook and all subsequent charts inherit it.
      


      
Side-by-side charts with plt.subplots()

      
python
fig, axes = plt.subplots(1, 2, figsize=(16, 5))

sns.histplot(data=vg, x='NA_Sales', bins=30, ax=axes[0])
axes[0].set_title('Distribution of NA Sales')
axes[0].set_xlabel('NA Sales (millions)')
axes[0].set_ylabel('Frequency')

sns.histplot(data=vg, x='EU_Sales', bins=30, ax=axes[1])
axes[1].set_title('Distribution of EU Sales')
axes[1].set_xlabel('EU Sales (millions)')
axes[1].set_ylabel('Frequency')

plt.tight_layout()
plt.show()


      
How plt.subplots() works:

      
    
        
  • plt.subplots(1, 2, figsize=(16, 5)) → 1 row, 2 columns of chart areas. fig = canvas, axes = array of chart areas.
    • 
        
  • ax=axes[0] → draw this chart in the first area. ax=axes[1] → second area.
    • 
        
  • axes[0].set_title(...) targets one specific chart. Use .set_title() (method on axes) not plt.title() (global) when multiple charts exist.
    • 
        
  • plt.tight_layout() adjusts spacing so labels don't overlap.
    • 
      


      

        
🌉 Tableau bridge

        Similar to placing two sheets side by side in a Tableau dashboard: you want to compare two views of the data simultaneously.
      


      
plt.tight_layout() — always include it

      
python
plt.figure(figsize=(12, 5))
sns.barplot(data=vg_top, x='Platform', y='Global_Sales')
plt.title('Average Global Sales by Platform')
plt.xlabel('Gaming Platform')
plt.ylabel('Average Global Sales (in millions of USD)')
plt.tight_layout()   # ← prevents label cutoffs at figure edges
plt.show()


      

        
✓ Professional chart checklist (interview standard)

        
    
          
  1. Has a descriptive, specific title
    2. 
          
  2. Has labelled axes with units (e.g. "millions", "USD")
    3. 
          
  3. Appropriately sized with plt.figure(figsize=...)
    4. 
          
  4. Includes plt.tight_layout() before plt.show()
    5. 
          
  5. Consistent style set with sns.set_style('whitegrid')
    6. 
        

        Meeting all five signals the attention to detail interviewers notice.

12Reference

      
When to use which chart — the decision framework

      
One of the most common interview questions: "Which chart would you use to visualize X?" Here's the decision framework.


      
      

        

          
          
          
          
          
        

        

          
Variable type: One categorical variable

          
Example question: "Which genre has the most games?"

          
sns.countplot()sns.barplot()

          
Use countplot for raw counts. Use barplot with a y variable for aggregated metrics (mean sales per genre). Always sort by frequency with order=vg['col'].value_counts().index.

        

        

          
Variable type: One continuous variable

          
Example question: "What does the distribution of sales look like? Are there outliers?"

          
sns.histplot()sns.kdeplot()sns.boxplot()

          
Use histogram first to see shape. Add kde=True for a density overlay. Follow with a box plot to identify outliers by the 1.5×IQR rule.

        

        

          
Variable type: Continuous × Continuous

          
Example question: "Do NA sales predict EU sales? How did game releases change over time?"

          
sns.scatterplot()sns.lineplot()

          
Use scatterplot for relationships at a point in time. Use lineplot when one variable is time or an ordered sequence. Add hue= to either to split by a categorical variable.

        

        

          
Variable type: Categorical × Continuous

          
Example question: "How does salary differ across departments? Compare revenue across regions."

          
sns.boxplot()sns.barplot()

          
Use box plot to compare full distributions (median, spread, outliers). Use bar plot to compare means. In interviews: show both and explain why — it signals thorough analysis.

        

        

          
Variable type: All numerical variables at once

          
Example question: "Which variables are most related? Give me an overview of this dataset."

          
sns.heatmap(df.corr())sns.pairplot()

          
Use heatmap for a quick numeric overview. Use pairplot to visually inspect each relationship. Start every EDA with these two — they tell you where to dig deeper.

        

      


      

        
Quiz 4

        
Dataset: employees with Department (categorical), Years_of_Experience (continuous), Salary (continuous). Manager asks: "How does salary differ across departments?" Which chart?

        

          
A) Scatter plot

          
B) Histogram

          
C) Grouped box plot

          
D) Correlation heatmap

        

        
Department is categorical, Salary is continuous → grouped box plot. It shows the salary distribution (median, spread, outliers) for each department, enabling rich comparison. A grouped bar plot showing mean salary would also be acceptable — in an interview, mention both and explain the difference.
