1 Why Python Visualization? (Tableau Users' Perspective)

You've already built charts in Tableau — drag a dimension to columns, drop a measure on rows, and you get a clean bar chart in seconds. Tableau is fantastic for that. So the natural question is: why would you bother writing code to make the same chart?

This question comes up in interviews. "Why use Python for visualization instead of Tableau or Power BI?" The answer isn't that one is better — it's that they serve different purposes in a real analyst workflow.

Tableau is a communication and dashboarding tool — built for interactive exploration, polished dashboards for business stakeholders, and letting non-technical people filter data themselves. If your goal is a dashboard your VP checks every Monday morning, Tableau is probably the right tool.

Python visualization is an analytical and automation tool. It lives inside your analysis notebook — for exploring data, checking distributions, spotting outliers, validating assumptions, and crucially, it can be automated.

Python wins when you need:

  • Automation — EDA inside a pipeline; no one is there to drag and drop.
  • Reproducibility — your notebook is your documentation; someone opens it six months later and sees exactly what you did.
  • Customization beyond GUI limits — correlation heatmaps, multi-panel grids are either impossible or clunky in Tableau.
  • Integration with analysis — your chart sits right next to the data-cleaning code and right before the modelling code.

Tableau wins for interactive dashboards, rapid visual exploration, and polished presentation-ready visuals with minimal effort.

🌉
Cross-Tech Bridge · Tableau

In Tableau, you explore data by pointing and clicking. In Python, you explore data by writing code. The analytical thinking is identical — the interface is different. By the end of this lecture, you'll be able to build the chart types you use most in Tableau, but in code, with some things Tableau simply can't do easily.

🌉
Cross-Tech Bridge · SQL

If you've used SQL, think about GROUP BY queries — you get aggregated numbers in a table, and Tableau visualizes that aggregation as a chart. Python visualization does both: you process data with Pandas (like SQL) and visualize it with Seaborn (like Tableau), all in one notebook.

4 Univariate Analysis: Categorical Data

🎯 Session Objective: The Manager's Questions
  • Which genre has the most games in our catalog?
  • What does the distribution of global sales look like?
  • Do games that sell well in North America also sell well in Europe?
  • How has the number of game releases changed over the years?
  • Which genre generates the highest average global sales?
  • Which regional sales figures are most closely related to global sales? And which regions' sales are least closely linked to each other?

The natural starting point in any EDA is to look at one variable at a time — univariate analysis. We start with categorical variables because they're the simplest to visualize and interpret.

Countplot

The first manager question: "Which genre has the most games in our catalog?" Genre is categorical; we want to count how many games fall into each category. The perfect tool is sns.countplot() — it counts occurrences of each category and displays them as bars.

python
plt.figure(figsize=(12, 5))
sns.countplot(data=vg, x='Genre')
plt.title('Number of Games by Genre')
plt.xlabel('Genre')
plt.ylabel('Count')
plt.show()
🌉
Cross-Tech Bridge · Tableau

In Tableau, you drag Genre to Columns and the system automatically adds a count to Rows. sns.countplot() does that count for you automatically. Same logic, different interface.

🗄️
SQL Analogy
SELECT Genre, COUNT(*) as game_count
FROM vgsales
GROUP BY Genre
ORDER BY game_count DESC;

When x-axis labels overlap, flip the chart by swapping x and y:

python
plt.figure(figsize=(10, 6))
sns.countplot(data=vg, y='Genre')
plt.title('Number of Games by Genre')
plt.xlabel('Count')
plt.ylabel('Genre')
plt.show()

Use the order parameter to sort by frequency — a professional touch that makes the chart immediately readable:

python
plt.figure(figsize=(10, 6))
sns.countplot(data=vg, y='Genre',
              order=vg['Genre'].value_counts().index)
plt.title('Number of Games by Genre (Sorted)')
plt.xlabel('Count')
plt.ylabel('Genre')
plt.show()
💡
Pro Tip

In interviews, always sort categorical bar charts by frequency unless there is a natural order (like months or ratings). It makes your analysis immediately readable. In our catalog, Action has the most games, followed by Sports.

Barplot (Frequency)

The same answer can also be shown with a bar plot. The difference: sns.barplot() does not count for you — you compute counts first, then plot them.

python
genre_counts = vg['Genre'].value_counts()

plt.figure(figsize=(12, 5))
sns.barplot(x=genre_counts.index, y=genre_counts.values)
plt.title('Number of Games by Genre')
plt.xlabel('Genre')
plt.ylabel('Number of Games')
plt.show()

This is still univariate analysis — only one variable, Genre, is involved. The bar heights come from value_counts(), not from another column.

Pie Chart (Brief Mention)

python
genre_counts = vg['Genre'].value_counts().head(5)
plt.figure(figsize=(7, 7))
plt.pie(genre_counts, labels=genre_counts.index, autopct='%1.1f%%')

Pie charts show proportions, but in professional data analysis and interviews, bar charts are almost always preferred. Human eyes are much better at comparing lengths (bars) than comparing angles (pie slices).

⚠️
Rule of Thumb

Use bar charts over pie charts in almost every situation. If you need to show proportions, a sorted bar chart with percentage labels is more readable than a pie chart.

5 Univariate Analysis: Continuous Data

When you have a continuous variable, you're analyzing a distribution — not counting categories. You want to know: What is the shape? Where is the center? How spread out is the data? Are there outliers? Three tools answer these questions.

Histogram

A histogram groups continuous values into bins and shows how many observations fall into each bin.

python
plt.figure(figsize=(10, 5))
sns.histplot(data=vg, x='Global_Sales', bins=30)
plt.title('Distribution of Global Sales')
plt.xlabel('Global Sales (millions)')
plt.ylabel('Frequency')
plt.show()

You'll notice immediately that the distribution is heavily right-skewed — most games have low sales, and a small number have extremely high sales. This is a very common pattern in real-world data: income, website traffic, app downloads, sales.

💡
Analogy

Think of income in a country. Most people earn a moderate amount, a smaller number earn a lot, and a tiny number earn an enormous amount. The histogram would have a tall cluster on the left with a long tail stretching right.

The bins parameter controls how many buckets the data is divided into:

python
plt.figure(figsize=(14, 4))

plt.subplot(1, 3, 1)
sns.histplot(data=vg, x='Global_Sales', bins=10)
plt.title('10 Bins')

plt.subplot(1, 3, 2)
sns.histplot(data=vg, x='Global_Sales', bins=30)
plt.title('30 Bins')

plt.subplot(1, 3, 3)
sns.histplot(data=vg, x='Global_Sales', bins=100)
plt.title('100 Bins')

plt.tight_layout()
plt.show()
⚠️
Rule of Thumb

Start with the default number of bins, then adjust. Blocky/oversimplified → increase bins. Noisy/jagged → decrease bins. 20–50 bins is usually a good range for most datasets.

KDE Plot

A KDE (Kernel Density Estimate) plot is a smoothed version of a histogram — instead of bars, it draws a continuous curve estimating the probability density of the variable.

python
plt.figure(figsize=(10, 5))
sns.kdeplot(data=vg, x='Global_Sales')
plt.title('KDE Plot of Global Sales')
plt.xlabel('Global Sales (millions)')
plt.ylabel('Density')
plt.show()

The y-axis is density, not count — the area under the curve sums to 1. You can also overlay a KDE on a histogram to get both views at once:

python
plt.figure(figsize=(10, 5))
sns.histplot(data=vg, x='Global_Sales', bins=30, kde=True)
plt.title('Histogram with KDE Overlay')
plt.xlabel('Global Sales (millions)')
plt.ylabel('Frequency')
plt.show()
💡
Pro Tip

In interviews, showing a histogram with a KDE overlay demonstrates that you understand distribution analysis at a professional level. A small touch that signals competence.

Box Plot

The box plot is your outlier detection tool — it compresses the entire distribution into five numbers and makes outliers immediately visible.

📦
How to Read a Box Plot

The box contains the middle 50% of the data (Q1 to Q3). The line inside the box is the median. The whiskers extend to the furthest data point within 1.5 × IQR beyond Q1 and Q3. Anything beyond the whiskers is a potential outlier — investigate before removing them.

python
plt.figure(figsize=(10, 5))
sns.boxplot(data=vg, x='Global_Sales')
plt.title('Box Plot of Global Sales')
plt.xlabel('Global Sales (millions)')
plt.show()

You'll see a compressed box on the left (most games have low sales) and many outlier dots stretching far right (blockbuster games). This confirms what the histogram already told us.

⚠️
IQR Rule — Interviewers Will Ask

IQR = Q3 − Q1  |  Lower Bound = Q1 − (1.5 × IQR)  |  Upper Bound = Q3 + (1.5 × IQR)

Any data point below the lower bound or above the upper bound is a potential outlier.

7 Bivariate Analysis: Continuous vs Continuous

So far we've looked at one variable at a time. But the most interesting analytical questions involve relationships between variables. Your manager now asks: "Do games that sell well in North America also sell well in Europe?" We need to look at two variables together.

Scatter Plot

A scatter plot places one continuous variable on x, another on y, and plots each data point as a dot — the most fundamental tool for visually assessing whether two variables are related.

python
plt.figure(figsize=(8, 6))
sns.scatterplot(data=vg, x='NA_Sales', y='EU_Sales')
plt.title('NA Sales vs EU Sales')
plt.xlabel('North America Sales (millions)')
plt.ylabel('Europe Sales (millions)')
plt.show()
PatternMeaning
Bottom-left → top-rightPositive correlation: as one increases, the other tends to increase
Top-left → bottom-rightNegative correlation: as one increases, the other tends to decrease
Random cloudNo clear linear relationship

Here, most points rise from bottom-left to top-right — games that sell well in North America generally sell well in Europe too. We'll measure how strongly in the heatmap section.

🌉
Cross-Tech Bridge · Tableau

In Tableau, you create a scatter plot by placing one measure on Columns and another on Rows. The Marks card shows circles by default. In Seaborn, you call sns.scatterplot() with x and y. Same logic, same visual output.

Line Plot

Line plots are best for showing trends over time or across ordered data. Your manager asks: "How has the number of game releases changed over the years?"

python
# Prepare the data
year_counts = vg.groupby('Year')['Name'].count().reset_index()
year_counts.columns = ['Year', 'Game_Count']
year_counts = year_counts.dropna()

plt.figure(figsize=(12, 5))
sns.lineplot(data=year_counts, x='Year', y='Game_Count')
plt.title('Number of Game Releases Over Time')
plt.xlabel('Year')
plt.ylabel('Number of Games Released')
plt.show()

The line plot shows the trend: game releases grew steadily, peaked around 2008–2009, then declined.

⚠️
Two Cautions About This Chart

Each row in this dataset is one game on one platform — a game released on three platforms counts three times. And the data stops around 2016, so the last few years are incomplete and exaggerate the decline.

💡
Pro Tip

Use scatter plots when you want to see the relationship between two variables at a point in time. Use line plots when one of your variables represents time or a natural sequence.

8 Bivariate Analysis: Categorical vs Continuous

What about comparing a continuous variable across categories? This is one of the most common patterns in real-world data analysis — "Compare revenue across regions," "Compare salaries across departments." The structure is always the same: one categorical variable defining groups, one continuous variable being compared.

Your manager's next question: "Which genre generates the highest average global sales?"

Grouped Bar Plot

python
plt.figure(figsize=(12, 5))
sns.barplot(data=vg, x='Genre', y='Global_Sales', errorbar=None)
plt.title('Average Global Sales by Genre')
plt.xlabel('Genre')
plt.ylabel('Average Global Sales (millions)')
plt.show()
💡
Note: errorbar=None

By default, sns.barplot() computes the mean of the y variable for each category on x. We set errorbar=None so that each bar shows only the average value without error bars, which keeps the chart clean and readable.

Platform games have the highest average global sales per game, followed by Shooter. Action has the most games but a lower average — it's crowded without being the top earner.

Now let's place a bar chart (countplot) and a grouped bar plot side by side to compare what each tells us:

plt.figure(figsize=(16, 5))

plt.xticks(rotation=45)

This is Tableau's most natural use case. You drag a dimension (Genre) to Columns and a measure (Global Sales) to Rows. You get a bar chart instantly. In Python, we have two tools for this: the grouped bar plot you just saw, and the grouped box plot next. Each shows something different.

Grouped Box Plot

Averages hide the spread. Your manager now asks: "How do global sales differ across gaming platforms?" — and wants to see more than the average.

A grouped box plot shows the full distribution of a continuous variable for each category — median, spread, and outliers for every group.

python
plt.figure(figsize=(14, 6))
sns.boxplot(data=vg, x='Platform', y='Global_Sales')
plt.title('Global Sales Distribution by Platform')
plt.xlabel('Platform')
plt.ylabel('Global Sales (millions)')
plt.xticks(rotation=45)
plt.show()

Filter to the top platforms for a cleaner view:

python
top_platforms = vg['Platform'].value_counts().head(8).index

plt.figure(figsize=(12, 6))
sns.boxplot(data=vg_top, x='Platform', y='Global_Sales')
plt.title('Global Sales Distribution by Top 8 Platforms')
plt.xlabel('Platform')
plt.xticks(rotation=45)
plt.ylabel('Global Sales (millions)')

Side-by-side comparison — univariate vs grouped box plot:

python
plt.figure(figsize=(16, 5))

plt.subplot(1, 2, 1)
sns.boxplot(data=vg_top, y='Global_Sales')
plt.title('Box Plot: Global Sales (Top 8 Combined)')
plt.ylabel('Global Sales (millions)')

plt.subplot(1, 2, 2)
sns.boxplot(data=vg_top, x='Platform', y='Global_Sales')

plt.xlabel('Platform')

The left chart shows one overall distribution: sales are skewed, with many outliers. The right chart splits that same data by platform, so you can see which platforms have higher typical sales and which ones produce the outliers.

9 Correlation Heatmap

We've covered individual charts for specific variable combinations. But what if you want to see the relationships between all the sales variables at once? Instead of making scatter plots one pair at a time, the correlation heatmap gives you the big picture in a single view.

The correlation heatmap computes the correlation coefficient between every pair of numerical variables and displays the results as a color-coded grid.

📊
Business Problem

Your manager asks: "Which regional sales figures are most closely related to global sales? And which regions' sales are least closely linked to each other?" Instead of making ten separate scatter plots, you can answer both questions with one chart.

First, compute the correlation matrix:

python
sales_cols = ['NA_Sales', 'EU_Sales', 'JP_Sales',
             'Other_Sales', 'Global_Sales']
vg[sales_cols].corr()

Now visualize it as a heatmap:

python
plt.figure(figsize=(10, 8))
sns.heatmap(vg[sales_cols].corr(),
            annot=True, cmap='coolwarm')
plt.title('Correlation Heatmap of Video Game Sales')
plt.show()

Key observations:

  • NA_Sales and Global_Sales: 0.94 — North American sales move most closely with global sales. Keep in mind that Global_Sales is the sum of all regional sales, so every region is partly correlated with it by construction. To compare markets with each other, read the region-vs-region cells, such as NA vs EU (0.77).
  • JP_Sales has the weakest correlation with other regions — the Japanese market is the least closely linked to the rest.
  • The diagonal is always 1.0.

Key parameters:

  • annot=True — prints the actual correlation values inside each cell. Without this, you only see colors, making precise interpretation difficult.
  • cmap='coolwarm' — red for positive, blue for negative, white for near-zero.
🌉
Cross-Tech Bridge · Tableau

Tableau does not natively produce correlation heatmaps. You'd need to compute correlations externally and then build a custom chart. This is one of the clearest examples of Python's advantage over Tableau for analytical visualization.

💡
Pro Tip

In an EDA notebook, a correlation heatmap is a quick way to show how numerical variables relate. It gives the reader an instant overview of your dataset's structure. Always include annot=True so the values are readable.

10 Styling, Labelling, and Figure Sizing

This section brings together everything needed to produce presentation-ready charts.

Setting a Visual Style

Seaborn comes with built-in styles that change the overall look of your charts:

python
sns.set_style('whitegrid')  # applies to every chart after this line
StyleDescription
'darkgrid'Grey background with grid lines
'whitegrid'White background with grid lines
'dark'Grey background, no grid
'white'White background, no grid
'ticks'White background with tick marks on axes
python
styles = ['darkgrid', 'whitegrid', 'dark', 'white', 'ticks']

fig = plt.figure(figsize=(20, 4))
for i, style in enumerate(styles):
    with sns.axes_style(style):
        ax = fig.add_subplot(1, 5, i + 1)
        sns.histplot(data=vg, x='Global_Sales', bins=20, ax=ax)
        ax.set_title(style)
plt.tight_layout()
plt.show()

# Set the style for the rest of the notebook
sns.set_style('whitegrid')
⚠️
Rule of Thumb

For professional notebooks and interviews, 'whitegrid' is the safest choice — clean, readable, and works well in both light and dark presentation settings.

Side-by-Side Charts with plt.subplots()

python
fig, axes = plt.subplots(1, 2, figsize=(16, 5))

sns.histplot(data=vg, x='NA_Sales', bins=30, ax=axes[0])
axes[0].set_title('Distribution of NA Sales')
axes[0].set_xlabel('NA Sales (millions)')
axes[0].set_ylabel('Frequency')

sns.histplot(data=vg, x='EU_Sales', bins=30, ax=axes[1])
axes[1].set_title('Distribution of EU Sales')
axes[1].set_xlabel('EU Sales (millions)')
axes[1].set_ylabel('Frequency')

plt.tight_layout()
plt.show()

Key points:

  • plt.subplots(1, 2, figsize=(16, 5)) creates 1 row and 2 columns of chart areas. fig is the overall figure; axes is an array of individual chart areas.
  • ax=axes[0] tells Seaborn to draw in the first chart area.
  • axes[0].set_title(...) sets the title for that specific chart area — use .set_title() (method on axes object) instead of plt.title() (global function) when you have multiple charts.
  • plt.tight_layout() adjusts spacing so labels don't overlap.
🌉
Cross-Tech Bridge · Tableau

This is similar to placing two sheets side by side in a Tableau dashboard — you want to compare two views of the data simultaneously.

Preventing Label Clipping

When axis labels or titles are long, they can get cut off. plt.tight_layout() automatically adjusts spacing to prevent this:

python
plt.figure(figsize=(12, 5))
sns.barplot(data=vg_top, x='Platform', y='Global_Sales',
            errorbar=None)
plt.title('Average Global Sales by Platform')
plt.xlabel('Gaming Platform')
plt.ylabel('Average Global Sales (in millions of USD)')
plt.tight_layout()
plt.show()
✅
Professional Chart Checklist

For interviews and professional notebooks, every chart should: (1) Have a descriptive title. (2) Have labelled axes with units. (3) Be appropriately sized. (4) Use tight_layout(). (5) Have a consistent style set with set_style(). Meeting all five signals attention to detail.

11 Wrap-Up: When to Use Which Chart

📋
Back to the Manager's Questions — Answers

Action is the most crowded genre, but Platform and Shooter games earn more per game. Sales are driven by a few blockbusters, so averages can mislead. North America moves most closely with global sales, and Japan is the least linked to the other markets. These charts describe the catalog; an investment decision would also need costs, recency, and market size.

One of the most common interview questions for Data Analyst roles: "Which chart would you use to visualize X?" Here's your decision framework:

Data Type CombinationRecommended ChartWhen to Use
One Categorical VariableCountplot, Bar ChartShow frequency or count of categories
One Continuous VariableHistogram, KDE Plot, Box PlotShow distribution, shape, outliers
Continuous vs ContinuousScatter Plot, Line PlotShow relationship or trend over time
Categorical vs ContinuousGrouped Box Plot, Grouped Bar PlotCompare a metric across groups
All Numerical VariablesCorrelation HeatmapOverview of all relationships at once

Example: Your manager says, "Show me how customer spending varies across membership tiers." Membership tier is categorical, spending is continuous. You reach for a grouped box plot (to show the full distribution per tier) or a grouped bar plot (to compare average spending). In an interview, you'd ideally show both and explain why.
